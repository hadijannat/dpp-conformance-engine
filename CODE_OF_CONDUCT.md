# Code of conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct.
The full text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
This file does not reproduce it.

## Scope

The code of conduct applies in all project spaces, and when a person represents the project.

## Reporting

Report unacceptable behavior by email to the maintainer named in [GOVERNANCE.md](GOVERNANCE.md):
<hadi.jannatabadi@rwth-aachen.de>.
The maintainer reviews each report and keeps the reporter's identity confidential.
