# GS1 linkset schema

Audience: contributors and reviewers.
Purpose: name the source and the license of the file in this directory.
Prerequisites: none.

`linkset-schema.json` is an unchanged copy of `linkset-schema.json` of the GitHub repository
`gs1/linkset`. The copy comes from commit `bedc11ec56527255369909509b7d06e471180472`. It was
retrieved on 2026-10-25.

The license is the Apache License, Version 2.0. The `LICENSE` file of the repository at the same
commit gives it. The `LICENSE` file of the repository names no copyright holder. So `REUSE.toml`
names the authors of the repository as the holder. A copy of the license is in `LICENSES/Apache-2.0.txt` of this repository.

The file is a JSON Schema draft-07 document for a linkset in the JSON format of RFC 9264. The
repository describes itself as a place to try out the linkset format of GS1 resolvers. So the
file is an independent cross-check, not the rule of a check.

The check `resolver.linkset` does not read this file. It applies its own structural rule (see the
architecture contract, section 8). The test `tests/test_adapters_resolver.py` validates the
linkset of the reference system against this file, with each seeded linkset fault. Only the
structure fault breaks the schema.

The SHA-256 of the file is `ff902c5a13f197727169cb8579e29ab598940bc266d90e8702191d7df392cf04`.
`catalogue/sources.yaml` holds one record for the file with the same value.

Do not edit this file. Its patterns contain the range `A-z`, as upstream does.
