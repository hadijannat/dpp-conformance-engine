# GS1 Digital Link test data

Audience: contributors and reviewers.
Purpose: name the source and the license of the file in this directory.
Prerequisites: none.

`dl.c` is an unchanged copy of `src/c-lib/dl.c` of the GitHub repository
`gs1/gs1-syntax-engine`. The copy comes from commit `58c1dc85d9ff4eb9368293bcf5264a9fe70bfc72`.

Copyright (c) 2021-2026 GS1 AISBL. The file is licensed under the Apache License, Version 2.0.
The header of the file and the `LICENSE` file of the repository at the same commit give this
license. A copy of the license is in `LICENSES/Apache-2.0.txt` of this repository.

GS1 publishes no separate data file of Digital Link URI test cases. The cases are in the C unit
test `test_dl_parseDLuri` of this file. The test `tests/test_external_vectors.py` reads the file
as text and extracts the cases. Nothing in the file is compiled or run.

`catalogue/sources.yaml` holds one record for the file with its SHA-256.

Do not edit this file. Git does not convert its line endings (see `.gitattributes`).
