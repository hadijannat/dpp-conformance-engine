# Wycheproof JWS test data

Audience: contributors and reviewers.
Purpose: name the source and the license of the file in this directory.
Prerequisites: none.

`TEST-ONLY-json_web_signature_test.json` is an unchanged copy of
`testvectors_v1/json_web_signature_test.json` of the GitHub repository `C2SP/wycheproof`. The
copy comes from commit `7a325932231bd7a724c791c8b0d65ea4d6d2f435`. Only the file name is
different. The prefix `TEST-ONLY-` marks the published test keys in the file.

Copyright 2016-2026 The Wycheproof Authors. The file is licensed under the Apache License,
Version 2.0. The `README.md` and `LICENSE` files of the repository at the same commit give this
license. A copy of the license is in `LICENSES/Apache-2.0.txt` of this repository.

The file holds published test keys, including private keys and HMAC keys. They protect nothing.

The test `tests/test_external_vectors.py` reads this file. `catalogue/sources.yaml` holds one
record for the file with its SHA-256.

Do not edit this file. Git does not convert its line endings (see `.gitattributes`).
