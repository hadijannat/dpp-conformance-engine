## Use in this project

The check `aas.dpp_compose` does not read this file at run time. It uses a table in
`src/dppce/adapters/aas.py`: the semanticId of the submodel, and the idShort, semanticId, and
cardinality of each top-level element. The test `tests/test_adapters_aas_dpp.py` derives the
same table from this file and asserts that the two are equal.

The concept descriptions of the file hold definition text that names a European standard as its
source. This project does not copy, quote, or summarize that text. The table holds identifiers
only.

`catalogue/sources.yaml` holds one record for the file with the same SHA-256.

Do not edit this file. Replace it only with an unchanged copy of a newer commit, and update the
table, this README, and the source record.
