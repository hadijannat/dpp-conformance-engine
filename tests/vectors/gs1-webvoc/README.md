# GS1 Web Vocabulary

Audience: contributors and reviewers.
Purpose: name the source and the license of the file in this directory.
Prerequisites: none.

`gs1Voc.jsonld` is an unchanged copy of `v1.16/gs1Voc.jsonld` of the GitHub repository
`gs1/WebVoc`. The copy comes from commit `f8f407bf717233c871dca2f62f4e45b0940e8cad`. It was
retrieved on 2026-10-27.

The license is the Apache License, Version 2.0. The `LICENSE` file of the repository at the same
commit gives it. That file names no copyright holder. The vocabulary names GS1 as its creator. So
`REUSE.toml` names GS1 AISBL as the holder. A copy of the license is in `LICENSES/Apache-2.0.txt`
of this repository. The file also holds a `schema:license` literal with the GS1 IP policy and a
disclaimer.

The file is the GS1 Web Vocabulary, version 1.16, in JSON-LD. Its size is about 2.3 MB. It starts
with a UTF-8 byte order mark.

The redaction of a Link header keeps the GS1 link types. `src/dppce/infrastructure/redaction.py`
holds them as a fixed list. The test `tests/test_external_vectors.py` reads each sub-property of
`gs1:linkType` from this file. It asserts that the list holds the same names. The engine does not
read this file at run time.

The SHA-256 of the file is `5b417c158cca7e55766dc5e35a1fa480273f036720b6c7382d61ea6939a7ee66`.
`catalogue/sources.yaml` holds one record for the file with the same value.

Do not edit this file.
