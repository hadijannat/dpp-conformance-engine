"Detected" counts killed and timed-out mutants. Both timeouts are in `merkle.verify_inclusion`
(mutants 31 and 36): the mutant loops without end, and the test run stops it.

An earlier attempt did not test any mutant. mutmut copied only the mutated directories, and
the copy could not import `dppce.models`. The configuration now copies `src/` and excludes the
other modules from mutation. That attempt is not in the table.

Between the runs, tests were added for the gaps that the survivors showed. See
`tests/test_mutation_gaps.py`. One gap was a defect: a token with a part that is not
base64url was reported as `BAD_SIGNATURE`. It is now `MALFORMED`.

## Limits of this record

- Mutation testing shows that the tests notice a change. It does not show that the code or
  the tests are right.
- The classification of the survivors was done by a script and checked by reading, by a
  development agent. A different reader can classify a mutant differently.
- The run used one host. The case-insensitive file system hides one mutant.
