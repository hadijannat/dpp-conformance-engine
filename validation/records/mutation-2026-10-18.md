## Survivors of the baseline

### Method

`uv run mutmut results` listed 837 survived mutants, 11 mutants with no tests, and 7 timeouts. For
each mutant, `uv run mutmut show` wrote the diff to a file. A development agent read each diff. A
scratchpad script then recorded the classes from rules that name each mutant number. The script
stops if a mutant has no rule or has two rules. The script did not choose any class.

The three classes are these:

- Equivalent: the mutant cannot change behavior on any input. "On this host only" marks a reason
  that depends on this host.
- Benign: the mutant changes only text or a value that no canonical body holds and no decision
  uses.
- Needs a test: any other mutant.

Text that enters a canonical body is classified as needs a test. Examples are `verdict_reason`,
`overall_reason`, and `TestResult.message`. Such text changes the decision digest and the replay of
a recording. The record of 2026-10-14 put such text in the class "No behavior depends on the text".
This record does not repeat that statement. It classifies such text again, as needs a test.
