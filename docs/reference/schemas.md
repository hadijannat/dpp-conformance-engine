# Schema reference

Audience: integrators and tool authors.
Purpose: list the published data contracts and where their JSON Schemas are.
Prerequisites: knowledge of JSON Schema.

This page is generated by `uv run just reference`. Do not edit it by hand.

The Pydantic models in `dppce.models` are the single source of truth. The JSON Schemas (draft 2020-12) in `src/dppce/schemas/v1/` are generated from them, and a test fails if they differ. Each document carries a `schema_version`. `dppce.migrations` upgrades an older document and rejects an unknown version.
