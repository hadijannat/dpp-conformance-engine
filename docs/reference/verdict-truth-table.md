## 5. Overall outcome

The overall outcome uses the applicable mandatory requirements only. Precedence: no such requirement gives `inconclusive` (an empty run cannot pass); then `fail`; then `error`; then `inconclusive`; then `pass`. See the architecture contract, section 7.4.
