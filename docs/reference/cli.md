# Command-line reference

Audience: operators and integrators.
Purpose: list each command of `dppce`, its options, and its exit codes.
Prerequisites: an installed engine.

This page is generated by `uv run just reference`. Do not edit it by hand.

Engine version: `0.1.0rc1`.

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | The command completed. For `run` and `replay`: the overall outcome is `pass`. |
| 1 | The system under test failed: the overall outcome is `fail`. |
| 2 | Usage or input error: bad arguments, an invalid file, lint errors, or an applicability rule that compares two different types. |
| 3 | Execution error: the overall outcome is `error`, or the engine failed. |
| 4 | Report verification failed or is incomplete, or a replay digest differs. |
| 5 | The run completed and the overall outcome is `inconclusive`. |

Each command accepts `--json` and then writes one JSON document to standard output.

## Commands

### `dppce plan`

```text
usage: dppce plan [-h] [--json] [--data-root DATA_ROOT] [--import-pack IMPORT_PACK]
                  [--import-testpack IMPORT_TESTPACK] --profile PROFILE --ics ICS --ixit IXIT
                  [--mode {illustrative,exploratory,reviewed}] [--pack PACK] [--testpack TESTPACK]
                  [--trust TRUST] [--authorization AUTHORIZATION] [--manual-result PATH] [--at AT]
                  [--issuer-name ISSUER_NAME] [--issuer-id ISSUER_ID]
                  [--accreditation-status ACCREDITATION_STATUS]
                  [--accreditation-reference ACCREDITATION_REFERENCE]

Show which requirements and test steps a run would select.

options:
  -h, --help            show this help message and exit
  --json                write one JSON document to standard output
  --data-root DATA_ROOT
                        directory with catalogue, profiles, and testpacks
  --import-pack IMPORT_PACK
                        import a requirement pack file
  --import-testpack IMPORT_TESTPACK
                        import a test pack file
  --profile PROFILE     profile identifier, for example battery/ev
  --ics ICS             implementation conformance statement
  --ixit IXIT           extra information for testing
  --mode {illustrative,exploratory,reviewed}
  --pack PACK           select one more pack by identifier
  --testpack TESTPACK   select one more test pack by identifier
  --trust TRUST         trust bundle (JSON); only the operator supplies it
  --authorization AUTHORIZATION
                        signed test authorization (compact JWS)
  --manual-result PATH  signed result of one manual step (compact JWS); only the operator supplies
                        it; repeat for each
  --at AT               evaluation time, for example 2026-10-13T12:00:00Z; default: now
  --issuer-name ISSUER_NAME
                        issuer name, declared by the operator; the verifier does not check it
  --issuer-id ISSUER_ID
                        issuer identifier; it must equal the issuer that the trust bundle names
                        for the report signing key
  --accreditation-status ACCREDITATION_STATUS
                        declared by the operator and not validated by the engine; a value other
                        than 'not accredited' needs --accreditation-reference
  --accreditation-reference ACCREDITATION_REFERENCE
```

```text
  --accreditation-status ACCREDITATION_STATUS
                        declared by the operator and not validated by the engine; a value other
                        than 'not accredited' needs --accreditation-reference
  --accreditation-reference ACCREDITATION_REFERENCE
  --out OUT             new directory for the run
  --keys KEYS           directory with the data keys; keep it apart
  --secrets SECRETS     directory that holds the file secrets of the roles
  --role-secret ROLE=REFERENCE
                        confirm the secret reference that the IXIT declares for one role; repeat
                        for each role
  --allow-private-host ORIGIN
                        confirm one loopback or private origin, such as http://127.0.0.1:8765;
                        repeat for each origin
  --allow-remote-host ORIGIN
                        state that the owner of one public origin permits bounded read-only
                        access; repeat for each
  --retention-days RETENTION_DAYS
                        days to keep the recording; the operator decides; default: the value that
                        the IXIT asks for
```

## Standalone verifier

`python -m dppce.verifier ENVELOPE --trust BUNDLE --at TIME` verifies a report without the orchestrator and without the system under test. Exit codes: 0 complete, 4 failed or incomplete, 2 bad input.
