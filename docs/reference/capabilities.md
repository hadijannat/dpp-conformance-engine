# Capability manifest

Audience: decision makers, vendors, and assessors.
Purpose: show what this version can do, and what it cannot do.
Prerequisites: none.

This page is generated by `uv run just reference`. Do not edit it by hand.

Engine version: `0.1.0rc1`. The command `dppce capabilities` prints the manifest of an installation, with the state of each optional dependency.

A capability with the state `interface_only` is a deferred integration. It is not an implemented feature. A capability that is not `supported` or `experimental` never gives a pass.

## Check parameters

Each check has a closed parameter model. The model refuses an unknown key, a value outside a fixed set, and a value of the wrong type. `dppce catalogue lint` reports such parameters with `CAT019`. `plan`, `run`, and `replay` refuse the test pack. The default is the value that the check uses when the key is absent.
