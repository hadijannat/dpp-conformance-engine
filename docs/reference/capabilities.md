# Capability manifest

Audience: decision makers, vendors, and assessors.
Purpose: show what this version can do, and what it cannot do.
Prerequisites: none.

This page is generated by `uv run just reference`. Do not edit it by hand.

Engine version: `0.1.0rc1`. This page describes the source that generated it. That source can be later than the release with this version string. The section Unreleased of `CHANGELOG.md` records changes after the last release.

The command `dppce capabilities` prints the manifest of an installation, with the state of each optional dependency.

A capability with the state `interface_only` is a deferred integration. It is not an implemented feature. A capability that is not `supported` or `experimental` never gives a pass.
